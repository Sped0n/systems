# Papercut

Record a papercut only when using another skill reveals reusable friction in
that skill:

- contradictory or stale guidance
- missing setup
- misleading errors
- a non-obvious recurring gotcha

Do not record project bugs, task-specific problems, environmental accidents, or
friction caused by choosing the wrong skill.

Write one or two sentences to:

`<project-root>/.pi/papercut-<skill-name>/<short-desc>-<timestamp>.md`

Use lowercase hyphenated names and a UTC timestamp formatted
`YYYYMMDDTHHMMSSZ`. The task is complete when one focused file records the
reusable skill friction without task-specific details.

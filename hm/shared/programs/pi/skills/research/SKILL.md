Research in the current session:

1. Investigate the question against **primary sources** — official docs, source code, specs, first-party APIs. Trace material claims to the source that owns them; distinguish verified facts, inference, and unresolved uncertainty.
2. Present findings with citations supporting the conclusions and consequential recommendations. Keep the depth proportional to the question.
3. When the user requests a saved report, write a single Markdown file where the repo keeps such notes. If no convention exists, choose a descriptive location and report it. Otherwise answer in the conversation; audit-only or read-only requests do not authorize a report file.
